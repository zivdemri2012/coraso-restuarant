# Maison Étoile

A portfolio website for **Maison Étoile**, a fictional French fine-dining restaurant in Paris.

Built with React 19 and Vite.

## Sections

- **Hero** – full-screen opening with calls to action
- **Our Story** – the restaurant and its chef
- **Menu** – signature dishes with Starters / Main Courses / Desserts filters
- **Experience** – the evening at Maison Étoile
- **Gallery** – photographs of the dining room and kitchen
- **Reservations** – a validated booking form (demo only: nothing is sent or stored)
- **Contact** – address, opening hours, and a hand-drawn SVG neighbourhood map

## Running locally

```bash
npm install
npm run dev      # development server
npm run build    # production build in dist/
npm run preview  # serve the production build
npm run lint     # oxlint
```
